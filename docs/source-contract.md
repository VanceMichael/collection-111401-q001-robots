# 合作站点访问约定

资料入口是 `/index`，页面资料位于 `/public/`。采集身份为 `CollectionBot`。站点通过 `/robots.txt` 公告 RFC 9309 规则，User-agent 分组、Allow/Disallow、最长匹配和路径编码遵循该规则；不支持的扩展字段不作为授权依据。授权仍以给定来源白名单为上界。

政策响应的 ETag 与 Cache-Control 描述有效版本。generation=2 关闭整个公开目录；mode=unavailable 返回 503；mode=absent 返回 404。短时不可达沿用尚有效的政策，超出有效期进入等待确认；404 是没有该公告，不扩张来源白名单。已在有效许可下发出的请求允许完成，尚未发出的请求按派发时有效政策判断。

本服务不主动阻止所有禁止路径，是否访问会出现在来源审计记录中。

## 本地演练控制

`GET /_health` 返回服务健康状态；`GET /_audit` 仅返回请求路径、方法和体积，不记录凭据。`POST /_control` 接收 JSON，可调整 generation、mode、clock。控制端点只服务于本地演练，不是资料接口，也不是浏览器业务操作入口。每次重新启动服务都会恢复初始数据；生产接入时不部署此控制面。
